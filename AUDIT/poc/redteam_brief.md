# Red Team Brief — Critical and High claims to disprove or prove

Claims only. No audit reasoning is included on purpose. Each row: claimed ID(s), one-line claim, where the claimant says it lives. Your job is to try to BREAK each claim, then PoC the survivors locally.

Deployment facts you may rely on: API = NestJS on 2 DigitalOcean App Platform containers + 1 identical "jobs" container (`.do/app.yaml`), Postgres via Supabase pooler, runtime role `loyalty_app` with RLS when `APP_DATABASE_URL` is set, owner role otherwise. Local: embedded Postgres via `pnpm db:dev`, API via `pnpm --filter @rfm-loyalty/api dev`, seed via `pnpm db:seed`.
